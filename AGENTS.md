## Agent skills

### Issue tracker

Track issues and specs as local Markdown files under `.scratch/<feature>/`. Read `docs/agents/issue-tracker.md` before creating, reading, or updating them.

### Triage labels

Use the five default triage roles as local issue status values. Read `docs/agents/triage-labels.md` before triaging issues.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Read `docs/agents/domain.md` before exploring the codebase.
