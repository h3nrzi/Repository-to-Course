# 02: Discover the module and study the first lesson

**What to build:** An anonymous visitor can discover the tele-bot preview, judge whether it fits their experience, and start the first problem-first lesson, Predict the behavior. Deliver a usable static learner journey with its real prepared content, establishing reusable delivery responsibilities within that slice.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] A catalog card identifies tele-bot, the repeated-`/start` problem, the target learner, and the limited preview, and opens the module introduction without account or payment requirements.

- [ ] State the four bounded objectives: trace the connected workflow; predict new/returning/changed-username behavior; explain state preservation and one bounded trade-off; make and locally validate the greeting change. Present these as learning objectives rather than established proficiency.

- [ ] Use Next.js and TypeScript static export with build-time Markdown and structured metadata. Catalog, introduction, lesson rendering, and navigation are reusable; repository-specific names, workflow, ordering, and lesson count remain content. No additional course is required.
