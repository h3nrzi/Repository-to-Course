# Repository-to-Course

The shared language for prepared, repository-based educational experiences.

## Language

**Fixed source revision**:
The immutable version of a teaching repository to which an educational release's source references and explanations correspond.

**Educational reconstruction**:
A teaching sequence arranged to explain a problem and its solution, without claiming to reproduce the project's actual development order or original reasoning.
_Avoid_: Development history, unless specific evidence supports that claim

**Course release**:
An identifiable, stable version of educational content, distinct from the fixed source revision it teaches.

**Creator publication approval**:
The creator's explicit authorization to distribute an exact course release within a stated scope, following rights, technical, and educational review.
